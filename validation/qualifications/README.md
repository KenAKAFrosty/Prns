# Qualification receipts

This directory contains hardware and protocol qualification receipts: bounded,
evidence-backed records of what was exercised against an exact implementation
or artifact. A receipt documents observed coverage and remaining limits; it
does not by itself promote a target to the shipping set or constitute release
acceptance.
