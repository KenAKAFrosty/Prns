# Flash artifact manifest source.
#
# build.rs turns this into:
# - OUT_DIR/flash_manifest.rs for the Dioxus UI
# - public/flash/manifest.json for release/CI tooling and external consumers
#
# Empty artifact_sha256 and artifact_size mean the release artifact is not
# published yet. The local_command field should still name a real repo path.
# Hosted release builds can set PRNS_FLASH_ARTIFACT_ROOT to a static artifact
# root containing firmware/... files; build.rs then stamps size/hash metadata and
# marks present artifacts as published without committing firmware into this tree.
