# Logo sources

`morsemicro.svg` uses the circular Mμ mark from the inline SVG logo in the navigation of [Morse Micro's official website](https://www.morsemicro.com/), retrieved on 2026-10-05. The mark's complete compound path, including its circular outline and letter cutouts, is unchanged; the canvas is limited to the mark and a descriptive title is added. Morse Micro also uses this standalone mark in its [official site icon](https://cdn.prod.website-files.com/6a4b36612c073faf65ec93f4/6a7d47952184435a865dcb07_Morse%20Micro%20Logo%20Icon%20only.png). The shared monochrome CSS mask follows the surrounding text color to identify the MM6108 radio vendor, without implying endorsement or permission beyond this identifying use.

`mediatek.svg` uses MediaTek's official **Secondary Logo White** SVG, downloaded on 2026-10-05 from its [brand asset library](https://www.mediatek.com/brand-logos-chips):

https://728015.fs1.hubspotusercontent-na1.net/hubfs/728015/Mediatek_Corporate_Assets_June2025/Brand_Logos_Chips_june2025/Svg/Secondary%20Logo_White.svg

The complete logotype's paths, proportions and white fill are unchanged. The SVG canvas is trimmed around the artwork with surrounding space retained, and a descriptive title is added. The site's shared monochrome CSS mask follows the surrounding text color; the wordmark gets additional horizontal room to remain readable.

MediaTek's [brand guidelines](https://www.mediatek.com/brand-assets) recommend the full logotype for small digital placements. This replaces the earlier custom M abbreviation. It identifies the MT7628 processor vendor on the ThinkNode G4 and Heltec HT-HD01-V2 cards, without implying endorsement.

`react.svg` is the React mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/react.svg), downloaded on 2026-10-05 and used unchanged with the shared monochrome CSS mask to identify React Native.
