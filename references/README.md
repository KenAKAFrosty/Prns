# Development References

`rtnode-heltecv4` is a pinned, read-only reference for Heltec WiFi LoRa 32 V3
and V4 hardware facts. It is GPL-3.0 and is never compiled, linked, packaged,
or required by Prns CI or release builds. PRNS implementations must remain
independent; this reference may only be used to cross-check hardware wiring and
bring-up behaviour.
